# Yasser Solar حلول الطاقة

حاسبة عربية عراقية مجانية لاختيار منظومات الطاقة الشمسية حسب الميزانية والحمل الليلي. تعمل بالكامل داخل المتصفح ولا تحتاج خادماً.

## الأسعار

الأسعار الابتدائية مخصصة للمقارنة فقط وليست عروض بيع. يمكن تعديلها من داخل الموقع وحفظها محلياً على الجهاز لتحديثها من قوائم شركات ومحلات أربيل.

## النشر

الموقع ثابت ومتوافق مع GitHub Pages مباشرة من الفرع الرئيسي.
